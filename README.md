# 🌌 Siddhesh Dinesh Gunjal - 3D Interactive Portfolio

An aesthetic, responsive 3D web developer portfolio built with **Three.js (WebGL)**, modern glassmorphic CSS, and semantic HTML5.

---

## 🚀 Features

- **Interactive 3D WebGL Canvas**:
  - Cosmic starfield particle system with color grading.
  - Textured, lighting-reactive 3D Moon with normal maps.
  - Rotating metallic Torus Knot core.
  - Custom 3D Avatar Cube featuring Siddhesh's photograph with neon wireframe accents.
  - Interactive mouse parallax & scroll-linked camera navigation.
- **Modern Cyber-Minimalist Aesthetic**:
  - Frosted glass cards (`backdrop-filter: blur()`).
  - Glowing accents and refined typography with *Space Grotesk*, *Outfit*, and *JetBrains Mono*.
  - Scroll progress bar, back-to-top button, and copy-to-clipboard email pill.
- **Deeply Analyzed Featured Projects**:
  1. **Advance AI ChatBot**: Multi-turn conversational AI with Google Gemini, Groq LLM failover, PostgreSQL/SQLite, deployed on Render.
  2. **W Weather — A Daily Field Report**: Atmospheric weather & air quality telemetry app with Open-Meteo API and US AQI gauges, deployed on Netlify.
- **Structured Showcase**:
  - Academic roots at **B.K. Birla College, Kalyan (W.)**.
  - Specialized toolkit (Python, AI Integration, PL/SQL, Three.js, Flask, PostgreSQL).
  - One-click contact launcher & social links (GitHub, LinkedIn, Email).

## 🛠️ How to Run Locally

### Option 1: Direct Browser / Live Server (No Build Needed!)
The portfolio uses standard ES Module import maps. You can open `index.html` directly using:
- **VS Code Live Server Extension**: Right click `index.html` → *Open with Live Server*.
- **Python**: Run `python -m http.server 3000` and visit `http://localhost:3000`.

### Option 2: Using Vite & Node.js
```bash
npm install
npm run dev
```
